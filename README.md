# Oryx & Ember Expeditions: tour operator website concept

A fictional East African safari company, built as a design showcase.

- **Live:** https://gabycrasher.github.io/concept-sites/tour-operator/
- **Signature opening:** a topographic map draws itself, a route traces across it with ticking coordinates, a passport stamp lands and opens like an iris onto the hero (about 3 seconds, once per visit, skippable).
- **Highlights:** scroll-driven route map with stops, season planner, trip builder, mobile swipe carousels, and a WhatsApp button for the designer.
- Static HTML/CSS/JS with GSAP + ScrollTrigger (vendored). Photos from Unsplash (credited in the footer).

The site lives in `tour-operator/`; the repository root forwards there. The company, guides and trips are invented, and the enquiry form does not send anything.
